## Day 3-4 — Eval harness (tests-first)

5. `tests/eval/run_eval.py` — entry point. Args: `--dataset`, `--api`, `--out`. Runs each transcript through `/analyze`, computes the 7 bars, writes `artifacts/eval.json` + a Markdown summary. Reports `mode=simulated|live` in the header. Simulated mode (Phase 2): bars 1-3 use a fixed-seed simulated-doctor-actions function. Live mode (Phase 3): reads doctor actions from the SQLite DB written by `/review-claim`.
6. `tests/eval/test_safety_regression.py` — for each category in `app/rules/blocked_advice.py:BLOCKED_CATEGORIES`, assert at least one transcript triggers it AND the response carries the safe replacement.
7. `tests/eval/test_missed_escalations.py` — for each `expected_red_flag_rules` entry across the dataset, assert the corresponding `/analyze` response contains an urgent claim that overlaps the rule's matched span.
8. `tests/eval/test_dataset_variety.py` — assert every §17 edge case is covered, §13.4 urgent transcript present, Indian-context (curd-rice-style) transcript present.
9. `tests/eval/test_no_phi.py` — calls `scripts/scan-phi.py`, asserts exit 0.

## The seven bars (must all be green for `make eval` to exit 0)

1. ≥80% of `direct` claims accepted-or-lightly-edited (`minor_wording` counts as lightly edited)
2. ≥60% of `interpretation` claims accepted (separate cohort; does not count toward bar 1)
3. ≤10% of all surfaced claims rejected
4. 100% of displayed claims have a visible evidence span (`evidence_text == raw_text[start:end]`)
5. 100% of medication-change advice blocked with safe replacement
6. Zero urgent-risk transcripts produce a silent (non-escalating) response
7. Every red-flag-rule match without a matching urgent claim is flagged as a missed escalation
